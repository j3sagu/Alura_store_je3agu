

# 📊 Análisis de Tiendas – Proyecto de Data Science

Este proyecto realiza un análisis de los ingresos y características de varias tiendas, con el objetivo de identificar cuál presenta menor rendimiento y puede ser considerada para venta.

---

## 📌 Descripción

A partir de datos históricos de 4 tiendas (ingresos, calificación de clientes, costos de envío y potencial de crecimiento), se aplicaron métricas estadísticas y comparativas para evaluar el desempeño de cada una.

El análisis se desarrolló en **Python** (Jupyter Notebook), utilizando librerías de análisis de datos como `pandas` y `matplotlib`.

---

## 📂 Contenido del proyecto

* **AluraStoreLatam.ipynb** → notebook principal con todo el análisis.
* **analisis/** → scripts auxiliares en Python (ejemplo: cálculo de ingresos totales por tienda).
* **README.md** → este archivo de documentación.

---

## 📈 Resultados principales

* La **Tienda 4** presenta los ingresos más bajos.
* No lidera en ninguna métrica clave (ingresos, calificación, potencial).
* Tiene un costo de envío bajo, pero esto no compensa su bajo rendimiento.
* **Conclusión:** la Tienda 4 es la más conveniente para ser vendida.
